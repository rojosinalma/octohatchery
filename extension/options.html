OctoHatchery extension

Changes save as you make them and apply at once.

Hatchery

The address you open the dashboard at. The browser asks you to allow access to this site only.

Alerts

Off: the extension sends no notifications at all. The alert settings below stay as they are and apply again when you turn this back on. The toolbar counters and the popup work either way, and "Count cancelled jobs as failed" still applies to the counters.

One notification when a runner takes a job. A job that starts and ends between two polls sends this alert and its result alert.

One notification when a job ends with the result success.

One notification when a job ends with failure or timed out (and cancelled, when the next setting is on). A job whose result is unknown sends no alert until GitHub reports the result.

On: a cancelled job counts and alerts as failed, like the dashboard's Failed filter. Off: a cancelled job counts as nothing and sends no alert.
Repos

Alerts only for the ticked repos. No repo ticked: alerts for every repo. The counters always count every repo.
Connect to a hatchery to list its repos.
Alerts use the notifications of the browser and the system. If nothing shows, check that the system lets the browser show notifications.

Toolbar counters

Live count: the jobs running now; it goes down when they end and the popup does not reset it. Started: the jobs that started since you last opened the popup. Both: two counters.

Jobs that succeeded since you last opened the popup.

Jobs that failed since you last opened the popup.

On: opening the popup sets the started, succeeded and failed counters to zero; the popup still shows what they were. Off: they keep counting until you click "Clear the counters" in the popup.

Drawn icon: every counter above zero gets a coloured tile on the toolbar icon (blue running, aqua started, green succeeded, red failed). Badge: the logo stays and a badge shows one count: failed first, then succeeded, then running. The tooltip of the icon always lists every counter.

Polling

How often the extension asks the hatchery for changes while the popup is closed. The browser allows 30 s at the shortest. While the popup is open it follows the live stream and updates within a second.

Appearance

On: the popup and this page use the skin, palette and mode set in the hatchery's own settings, and change when they change there. Off: you pick them here, for this browser only.
Skin, palette and mode

Applies at once to this page and the popup. The sun and moon button switches between dark and light; it is off when the palette has one mode only.
